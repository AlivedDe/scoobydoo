# Description

The ScoobyDoo problem is a short exercise in coding. The solution should print out the numbers 1 through 100, except it should instead print `Scooby` if a given number is divisible by 5 and `Doo` when it is divisible by 7. If it is divisible by both, it should print `ScoobyDoo`. You may be as creative as you like in your solution. Please record yourself coding the solution and narrate what you're doing.
